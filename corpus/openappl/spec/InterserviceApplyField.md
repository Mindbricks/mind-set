# InterserviceApplyField

**Level:** `subsection` · **Family:** [BusinessApiActionStore](../ontology/families.md#businessapiactionstore) (domain `BusinessApi`)

**Ontology:** [InterserviceApplyField in Part 1](../ontology/InterserviceApplyField.md)

A guarded single-field update on another service's record, applied through that service's typed update API, where the field NAME is computed at runtime and whitelisted at design time. It is the `applyField` block of an InterserviceCallAction and replaces its `apiParameters`: the generated request carries exactly one data key, the field `field` evaluated to, set to `value`, on the record `recordId` names. Design-time rules: the target API must be an `update` API (INTERSERVICE_APPLY_FIELD_TARGET_NOT_UPDATE) whose effective REST route carries exactly one `:segment` and that segment is its id segment, `:id` or `:` followed by the data object name and `Id` (INTERSERVICE_APPLY_FIELD_TARGET_NOT_ID_ADDRESSED); its write set must be statically known, so an update API with no dataClauseItems, an action-carried write, an unresolvable data object or no declared request parameters is refused (INTERSERVICE_APPLY_FIELD_TARGET_SURFACE_UNKNOWN); every `allowedFields` entry must be in that write set (INTERSERVICE_APPLY_FIELD_NOT_UPDATABLE); `apiParameters` must be empty (INTERSERVICE_APPLY_FIELD_WITH_API_PARAMETERS); `transport` must not be `grpc` (INTERSERVICE_APPLY_FIELD_TRANSPORT_UNSUPPORTED); the calling service must generate in nodejs, rust, java or dotnet (INTERSERVICE_APPLY_FIELD_LANGUAGE_UNSUPPORTED; the python and golang emitters do not implement it yet). Runtime refusals, all before any token or I/O: 400 INTERSERVICE_APPLY_FIELD_NOT_ALLOWED for a `field` result that is not a string or not exactly one of the allowed fields, 400 INTERSERVICE_APPLY_FIELD_VALUE_UNDEFINED for an undefined `value`, 400 INTERSERVICE_PATH_PARAM_UNBOUND for a null or blank `recordId`. The target's own authorization still decides whether the call may update the record.

## Properties

| Name | Type | Required | Default | Allowed values | Details | Description |
| --- | --- | --- | --- | --- | --- | --- |
| `recordId` | [`MScript`](./MScript.md) | yes |  |  | MScript kind `code` | MScript yielding the id of the record to update on the target service. It binds the one `:segment` of the target update API's REST route, its id segment (`:id` or the data object name followed by `Id`). A null or blank result refuses the call at runtime with 400 INTERSERVICE_PATH_PARAM_UNBOUND before any token or I/O. |
| `field` | [`MScript`](./MScript.md) | yes |  |  | MScript kind `code` | MScript that evaluates at runtime to the NAME of the single target request parameter to set; it must be one of `allowedFields`. The name lives in the same namespace as `apiParameters[].name`: the request parameters of the target update API, which for a generated update API are the data object property names. A result that is not a string, or not exactly (case-sensitive) one of `allowedFields`, refuses the call with 400 INTERSERVICE_APPLY_FIELD_NOT_ALLOWED; the message names the refused field name, never the value. |
| `value` | [`MScript`](./MScript.md) | yes |  |  | MScript kind `code` | MScript yielding the value to apply to the chosen field. `null` is a value and is sent (it clears a nullable property, subject to the target's own checks). `undefined` refuses the call with 400 INTERSERVICE_APPLY_FIELD_VALUE_UNDEFINED, because a request without the key would reach the target as an update of nothing. |
| `allowedFields` | `String`[] | no |  |  |  | The design-time whitelist: the names `field` may evaluate to. It must hold at least one non-blank string (INTERSERVICE_APPLY_FIELD_ALLOWED_FIELDS_EMPTY). Each entry must be in the target update API's write set, matched exactly and case-sensitively: a request parameter the caller can send, declared at httpLocation body or query (not `id`, not the id segment, not contractOnly; an omitted location, bearer, session, header, cookie, request or urlpath is refused, a cookie one as UNSUPPORTED_LOCATION) that one of the target's dataClauseItems reads as `this.` plus the parameter name and stores into a property that is writable on update (not `allowUpdate: false`), whose wire key (its `dataPath`, else its name) is not `__proto__` (UNSAFE_WIRE_KEY: a request body cannot carry it; give the parameter another dataPath), and whose wire key no other request parameter of the target reads from the request (WIRE_KEY_SHARED: the one value would be stored twice; only a parameter at urlpath, session, header or request is read elsewhere, every other location, cookie included, is read from the body or the query string). An entry outside that set is INTERSERVICE_APPLY_FIELD_NOT_UPDATABLE, which names the entry, the target and the accepted set, with the reason UNKNOWN_AT_TARGET, NOT_STORED, IMMUTABLE, SERVER_POPULATED_LOCATION, RECORD_ID, UNSUPPORTED_LOCATION, WIRE_KEY_SHARED or UNSAFE_WIRE_KEY. |

## Constraints

Property rules:

- `recordId`, `field`, `value` must be present. (`REQUIRED_FIELD_MISSING`)
