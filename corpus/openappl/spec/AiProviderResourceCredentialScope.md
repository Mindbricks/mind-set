# AiProviderResourceCredentialScope

**Level:** `subsection` · **Family:** [ProjectSettings](../ontology/families.md#projectsettings) (domain `Project`)

**Ontology:** [AiProviderResourceCredentialScope in Part 1](../ontology/AiProviderResourceCredentialScope.md)

The resource level of one AI provider entry's scoped credentials: which data object's rows may own a key, how the row is found from a call, and which member roles manage and use the key. Validation: `dataObject` must name a data object of the project whose `membershipSettings.hasMembership` is true with `membershipObjectName`, `membershipObjectIdProperty` and `membershipUserIdProperty` set (an owner field alone is the user level, not this one); `managers` and `users` must be roles the membership role field can carry (the `rolePermissions` roles, the role property's enum options, or the built-in `member` of a roleless membership), compared case-insensitively; with `managers` empty the object needs an owner field (`sessionSettings.isOwnerField`), because only the creator could ever set a key; `idFrom` is required unless `mode` is `off` and must be a property path of `params` or `session`; one data object name may be resource-scoped in one service only, because a key's owner is `<object>:<row id>`; `budget.dailyCostCeilingUsd` must be a positive number; the brand must support scoped keys (google, azure-openai, bedrock, ollama and mock cannot take this level; fal and custom warn that saved keys are stored unverified); and an AgentHarness with `modelSettings.auth: userSubscription` may not use an entry whose resource mode is not `off`.

## Properties

| Name | Type | Required | Default | Allowed values | Details | Description |
| --- | --- | --- | --- | --- | --- | --- |
| `mode` | `ProviderCredentialScopeMode` | no | `"off"` | `off`, `optional`, `required` |  | `off` (default), `optional` or `required`. `optional`: a member's call uses the row's key when the row has one, and falls through to the tenant and saas levels otherwise. `required`: a call that names a row must use that row's key; with no key, or when the caller is not a member of the row, it fails with HTTP 428 `AI_PROVIDER_CREDENTIAL_REQUIRED` naming the resource, and the saas key is never used. A `required` resource level makes the saas key in `configuration` optional, as a required tenant or user level does. Runs with no verified human actor (cron, a system session) skip the level, even when it is `required`. |
| `dataObject` | [`DataObjectName`](./DataObjectName.md) | no |  |  | names a [DataObject](./DataObject.md) | The data object whose rows own the keys, e.g. `workspace`. It must carry a complete membership configuration (`objectSettings.membershipSettings`). The service that declares the object owns the level: it runs the membership check and serves the key management of its rows. Use `serviceName:objectName` when the bare name is not unique in the project, to pick the service; every entry that names the object must then pick the same service, since a key's owner is `<object>:<row id>`. |
| `idFrom` | [`MScript`](./MScript.md) | no |  |  | MScript kind `code` | A property path of `params` or `session` that yields the row id (a string), e.g. `{ "js": "params.workspaceId" }`, `session.workspaceId` or `params['workspace-id']`. `params` is the call's parameters (a business API's resolved parameters, an agent's run input, a harness session's start body, the chat body's `context`), and `session` the verified caller session (attributes only). It is a path, not an expression: dot steps and quoted-string brackets only, no call, operator, function, template literal, computed key or optional chain, and no step through `constructor`, `__proto__` or `prototype`; anything else is a validation error. The path is language-neutral: a source for another language, when given, must be the same path or another path of `params` or `session`. `this` and `request` are not available, because the same path serves every caller. A value that is not a string reads as "no row named": the level is then skipped (`optional`) or refused (`required`). |
| `managers` | `String`[] | no |  |  |  | Member roles that may set, replace and delete the row's key, e.g. `["admin"]`. The row's creator (its `isOwnerField` property) always may. Each name must be a role of the data object's membership configuration. Empty: only the creator manages the key, which needs an owner field on the object. |
| `users` | `String`[] | no |  |  |  | Member roles whose calls may use the row's key, e.g. `["member", "admin"]`. The creator and the managers always may. Each name must be a role of the data object's membership configuration. Empty: every member whose membership row passes the configured status check. |
| `budget` | [`AiProviderResourceCredentialBudget`](./AiProviderResourceCredentialBudget.md) | no |  |  |  | Optional spend limit for calls made on a row's key. Under `costPolicy: ownerPays` the cost governors (agents, agentHub and AgentHarness sessions, the MCP-BFF chat) compare it with that row's own daily spend before every call; past it the call is refused `429 AGENT_BUDGET_EXCEEDED` with `bucket: resource` and the row id. Other rows, and the application owner's budgets, are never read or charged. Absent = no ceiling for the row (the per-user daily token budget still applies). |

## Constraints

Property rules:

- `mode` must be one of the allowed values (compared case-insensitively). (`INVALID_ENUM_VALUE`)
- `dataObject` must be a well-formed [`DataObjectName`](./DataObjectName.md) (a data object, optionally qualified by its service (`service:object`)). (`INVALID_DATA_OBJECT_NAME_FORMAT`)
