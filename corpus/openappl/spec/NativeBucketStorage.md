# NativeBucketStorage

**Level:** `section` · **Family:** [NativeBucket](../ontology/families.md#nativebucket) (domain `Service`)

**Ontology:** [NativeBucketStorage in Part 1](../ontology/NativeBucketStorage.md)

Storage configuration for a NativeBucket. Slim, provider-less variant of RemoteBucketStorage — there is NO `providerName` because the store is the platform-managed SeaweedFS (resolved from project-scoped NATIVEBUCKET_* env at runtime, forcePathStyle always true). Keeps the object-store knobs: optional physical-bucket override, key prefix, URL strategy, presign TTL, and server-side encryption.

## Properties

| Name | Type | Required | Default | Allowed values | Details | Description |
| --- | --- | --- | --- | --- | --- | --- |
| `nativeBucketName` | `String` | no |  |  |  | Optional override for the physical bucket name in the managed SeaweedFS store. If null, falls back to the project's managed default bucket (`<codename>-native`), which the deployer/FARM creates. When set it must be a valid S3 bucket name (3 to 63 characters, lowercase letters, digits, dots and hyphens, starting and ending with a letter or digit, no adjacent dots, not IP-shaped): a camelCase codename such as `kycDocs` is a design-time error (NATIVE_BUCKET_NAME_INVALID). Physical bucket names are shared by every project of the cluster, so the name must also start with the project codename and a dash (`<codename>-` followed by a name, e.g. `<codename>-kyc-docs`); any other name is a design-time error (NATIVE_BUCKET_NAME_FOREIGN). The bucket is provisioned by the hosting platform — it is not the designer's responsibility. |
| `keyPrefix` | `String` | no |  |  |  | Optional path prefix added to every stored object key (e.g., 'avatars/' produces keys like 'avatars/{uuid}'). Useful when multiple native buckets share the managed default physical bucket. |
| `presignTTLSeconds` | `Integer` | no | `900` |  |  | Lifetime of a presigned URL in seconds. Default 900 (15 minutes). Downloads are always served as a short-lived presigned URL — the service authorizes the request, then the client fetches directly from the storage provider. A presigned URL is a BEARER credential — anyone holding it can fetch the object until it expires, and it CANNOT be revoked early — so the TTL is the exposure window if the URL leaks (logs, Referer headers, shared links). 15 minutes is the common industry range for user-facing downloads. Note a short TTL does NOT truncate large downloads: the signature is checked when the request STARTS, so a transfer that begins before expiry completes normally. Raise it only for batch or machine consumers that hold a URL before using it. |
| `serverSideEncryption` | `Boolean` | no | `false` |  |  | When true, enables server-side encryption (SSE-S3 / AES256) on the managed SeaweedFS store. Default: false - SSE is OPT-IN. The managed store only accepts the signed `x-amz-server-side-encryption: AES256` header when it was provisioned with an `[s3.sse] kek` in its security.toml; without one every PUT answers 500 InternalError while CreateBucket/HeadBucket still succeed (docs/ADR-seaweedfs-nativebucket.md section 8.2). Turn it on only against a store confirmed to carry a KEK. |
| `objectCacheControl` | `String` | no | `null` |  |  | Cache-Control this bucket's objects are stored and served with. Null (the default) means the framework value `public, max-age=31536000, immutable`, which is right for content-addressed assets and wrong for a bucket that holds mutable documents: set for example `no-cache` for a rendered report rewritten in place through the SDK, `private, max-age=60` for a regulated bucket, `public, max-age=300` for a scratch area. The value is set on BOTH sides of the round trip - the stored object metadata (S3 `CacheControl`) and the `Cache-Control` entry of the `headers` map the presigned upload returns, plus the signed GET-side response override (`ResponseCacheControl`) - because the read-time override wins over what is stored. The managed store is S3-API, so both carriers apply; changing this field affects objects written AFTER the change and never retroactively rewrites objects already in the bucket. Must be a plausible Cache-Control token list (comma-separated `directive` or `directive=value`); a malformed value is an authoring-time error, because the store keeps the string verbatim and then serves it to every browser. |
