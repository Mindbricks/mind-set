# IntegrationParameter

**Level:** `subsection` · **Family:** [BusinessApiActionStore](./families.md#businessapiactionstore) (domain `BusinessApi`)

**Specification:** [IntegrationParameter in Part 2](../spec/IntegrationParameter.md)

Defines a single named input to be passed to a native integration provider action. Parameter values are evaluated using MScript and can be derived from session, context, or external input.

## Contained in

- [IntegrationAction](./IntegrationAction.md) as `parameters` (a list)

## Contains

No other pattern: every property is a value or a reference.

## References

None: no property names another pattern instance.
