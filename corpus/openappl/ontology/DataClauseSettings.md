# DataClauseSettings

**Level:** `unclassified` · **Family:** [Standalone patterns](./families.md#standalone-patterns)

**Specification:** [DataClauseSettings in Part 2](../spec/DataClauseSettings.md)

Defines additional data values to be used in create or update operations. This clause augments the auto-generated data object by injecting or overriding values from context.

## Contained in

No property of another pattern holds this pattern.

## Contains

No other pattern: every property is a value or a reference.
