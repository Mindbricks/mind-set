# EnterpriseAction

Declare a named enterprise function in an enterprise model. Use the function identifier from the provider's metadata, then reference the declaration by `name` from the invoking business API's external action. A missing function identifier or invalid declaration name must be corrected in the enterprise model before wiring the call.

See the [pattern reference](../../spec/EnterpriseAction.md) and the [enterprise provider guide](../../spec/providers/enterpriseIntegration.md).
