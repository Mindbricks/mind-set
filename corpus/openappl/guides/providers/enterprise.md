# Enterprise integration behavior

An enterprise integration binds a named provider, an external model and its operations. Map fields and function identifiers from the provider's metadata. An action uses the function identifier declared for its model. Refresh and compare the metadata before changing a mapping.

See the [configuration keys](../../spec/providers/enterpriseIntegration.md) and the [related guide](../actions/enterprise-action.md).

## Operations

Use the compiler's operations guide for environment and console setup.

For the Genesis compiler, these operations (environment variables, console configuration, credential setup, webhook registration and the go-live checklist) are in the `genesis-set` package, which installs next to mind-set.
